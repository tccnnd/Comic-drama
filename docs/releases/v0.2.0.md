# Release v0.2.0 - video-provider-mainline

Date: 2026-06-06
Updated: 2026-06-24 with live XL validation evidence
Branch: `codex/video-provider-mainline`

## Summary

Makes scene-level real video generation the primary rendering path, with local
2.5D as an explicit, observable fallback. Adds a first-class `shot_plan`,
per-scene generation provenance, canonical-timeline enrichment, a unified
fallback policy, and Review Console visibility into how each scene was
produced.

## Highlights

- `shot_plan`: persisted per scene; derived from `temporal_spec.shots` or
  synthesized as a single full-duration shot.
- `generation_meta`: `provider_id`, `provider_label`, `backend`,
  `is_real_video`, `fallback_used`, `attempts`, `duration_seconds`,
  `fallback_mode`, sanitized `error`, `warnings`, and `generated_at`.
- `canonical_timeline`: per-clip `metadata.generation`, `shot_plan_source`,
  and summary counts for real-video scenes and fallback scenes.
- Unified fallback policy: `VIDEO_FALLBACK_MODE=report|strict|silent` with
  `VIDEO_STRICT` override; default is `report`.
- Review Console: per-scene real-video/fallback/unknown badge, provider label,
  attempts, failure reason, and project-level provider readiness.

## AC-7 Acceptance

The original release workflow was run end-to-end with a local keyframe provider
to bypass the environment-blocked ComfyUI keyframe tunnel:

```powershell
python -m scripts.run_workflow --input inputs\sample_story.txt --keyframe-provider local
```

That run produced a final video and `canonical_timeline.json`, validated
`shot_plan`, timeline provenance, and live report-mode fallback.

A later controlled live XL provider run validated the scene-level real-video
success branch:


## Caveats

- This release validates scene-level real-video generation. It does not provide
  official shot-level real-video rendering.
- ComfyUI keyframe tunnel remains environment-blocked in this workspace with
  `Error reading SSH protocol banner`; use `--keyframe-provider local` for the
  reliable demo path.
- Live provider validation consumes quota and should remain explicit.
